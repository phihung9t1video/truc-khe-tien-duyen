# Trúc Khê Tiên Duyên

Game nhập vai kiếm hiệp – tiên hiệp 2D chạy trên trình duyệt và điện thoại Android.

- **Chơi ngay trên web:** https://phihung9t1video.github.io/truc-khe-tien-duyen/
- **Tải APK Android:** https://github.com/phihung9t1video/truc-khe-tien-duyen/releases/latest/download/truc-khe-tien-duyen.apk

## Nội dung
- 3 môn phái (Thiên Kiếm Tông, Xích Diễm Cốc, Bích Thủy Các), mỗi phái 4 võ công.
- 6 vùng đất cấp 1–60 nối bằng Truyền Tống Trận, 42 nhiệm vụ, 6 trùm.
- 11 ô trang bị, 10 bậc, 4 độ hiếm. Ngự kiếm phi hành. Chế độ tự động.
- Online: thấy người chơi khác cùng vùng, chat thế giới, bảng xếp hạng, lưu nhân vật lên mạng bằng mã khôi phục.

Toàn bộ hình ảnh, âm thanh do game tự vẽ và tự tạo bằng mã, không dùng tài nguyên của game khác.

## Phát triển
- Chơi thử trên máy: mở `index.html`.
- Phát hành bản mới (web + APK): chạy `PHAT-HANH.bat`.
- Bật bảng xếp hạng và lưu đám mây: chạy `supabase/schema.sql` trong Supabase SQL Editor.
